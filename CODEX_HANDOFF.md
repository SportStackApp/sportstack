# Codex Handoff

Future agents should start by reading these files in order:

1. `AGENTS.md` — repo-specific operating rules, safety constraints, branch conventions, and testing expectations.
2. `docs/project-brief.md` — concise product, architecture, and current-priority context.
3. `TECHNICAL_SPECIFICATION_AND_SYSTEM_HANDOFF.md` — fuller technical handoff and implementation context.
4. `PROJECT_SCOPE_UI_UX_AND_IMPLEMENTATION_PLAN.md` — scope, UI/UX direction, and implementation plan.

Treat the live Supabase database as the source of truth, keep changes small and scoped, and confirm with the owner before any destructive or deployment-sensitive work.
