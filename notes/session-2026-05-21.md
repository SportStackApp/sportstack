# Session Handover — 21 May 2026

## What we worked on

### 1. Player MVP Voting — Design complete, database built
- Full design finalised:
  - Players vote 3/2/1 (like AFL BOG)
  - Only players who attended the game can vote or be voted for
  - No self-votes
  - Unique email link per player (no login required)
  - 72-hour voting window with reminders at 48h and 24h
  - Admin can reopen, resend, close manually
  - Admin vote adjustments with full audit trail
  - Triggered 10 minutes after game end time, based on RevSports scraped data

- 5 new Supabase tables created (migration applied):
  - `revsports_players` — scraped player/game data from RevSports CSVs
  - `mvp_voting_sessions` — one row per game with voting
  - `mvp_vote_tokens` — secret email link token per player per session
  - `mvp_votes` — 3/2/1 vote lines
  - `mvp_vote_audit` — full log of every admin change
