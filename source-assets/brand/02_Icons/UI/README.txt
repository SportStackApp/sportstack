UI feature icons (24x24). Two styles: Line and Solid.
Theme-aware: the main colour uses currentColor (set it via CSS 'color').
Accent uses var(--icon-accent) (default #16A34A). Knockouts use var(--icon-bg) (default #ffffff).
Dark mode: set color to a light tone (e.g. #E5E7EB) and --icon-accent to #22C55E; set --icon-bg to your dark surface.
